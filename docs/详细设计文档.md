### 3.1 Domain 层（纯 Kotlin）

#### 3.1.1 `SpeedPolicy.kt` — 倍速档位域（v1.4）

```kotlin
enum class PlaybackSpeed(val value: Float) {
    S0_5(0.5f), S0_6(0.6f), S0_7(0.7f), S0_8(0.8f), S0_9(0.9f), S1_0(1.0f);
    companion object {
        fun from(value: Float): PlaybackSpeed = entries.minBy { abs(it.value - value) }
        val DEFAULT: PlaybackSpeed = S1_0
    }
}
```
- 职责：把播放速度收敛为六档枚举；禁止在 UI/ViewModel 层出现任意 float 倍速（满足 I4）。
- 校验：任何 `Float` 倍速必须经 `from()` 取最近档位后再下放引擎。

#### 3.2.2 `VideoPlayerManagerImpl` 内部组件协作

| 组件 | 职责 | 关键实现 |
|------|------|----------|
| `ExoPlayerHolder` | 创建/持有 ExoPlayer；配置 `DefaultRenderersFactory.setEnableDecoderFallback(true)`、`setAudioAttributes(…, handleAudioFocus=false)`、默认 1.0x | 生命周期绑定 Activity/Lifecycle（`ON_START/ON_STOP`） |
| `SelectionMonitor` | 单次区间模式：监听 PositionTick，`enginePos ≥ B'` 且 `!continuousLoop` → `pause()`+`seekTo(A')`+发 `SelectionHit`；去抖（触发后 500ms 屏蔽 + `hitAck` 复位标志） | 防重复：`hasFired` 在 seek 完成、位置 < B'−50ms 后复位 |
| `LoopMediaSourceBuilder` | 连续循环模式源构建；每次整链重建（新 original） | 复用受控：禁止跨 `setMediaSource` 复用（架构 P1-6） |
| `PlayerObserver` | 订阅 `Player.Listener`；250ms 轮询 PositionTick；交互事务后主动读一次位置立即 emit | 双通道（架构 6.3） |
| `PositionNormalizer` | 连续循环态 `display = A' + (engine % (B'−A'))`；单次模式直读 | 幂等纯函数，单测覆盖 |
| `CountdownController` | FR-10：画面冻结 + 音频先行 3s + 结束对齐 | 见 §4.3 时序 |
| `AudioDelayController` | 装配 `AudioDelayProcessor(delayMs)`；±100ms/5ms；暂停态重建音频链即时生效 | spike 验证与 Sonic 共存（R-13） |
| `OrientationAdapter` | 读 `METADATA_KEY_VIDEO_ROTATION`；`onVideoRotationChanged` 兜底 | rotation 0/90/180/270；缺失→默认横屏（R-11） |
| `FrameGrabber` | `MediaMetadataRetriever.getFrameAtTime(us, OPTION_CLOSEST)` / 渲染帧捕获 | IO 线程；Bitmap ≤ 宽 320px（R-12） |
| `AudioFocusHelper` | 统一焦点策略（架构 10） | `MAY_DUCK→duck`；其余→pause；恢复不自动播放 |

#### 3.2.3 倒计时预听的两种实现路径（MVP spike 决定，架构 7.6/R-03c）

| 路径 | 做法 | 取舍 |
|------|------|------|
| A：静态帧遮罩 | 引擎从 `S−3s` 正常 play（音视频都在走），渲染层用 S 帧 Bitmap 覆盖视频 Surface，倒计时结束移除遮罩 | 实现简单可靠；画面在遮罩下是静止帧，音画天然对齐 |
| B：视频渲染器暂停 | 仅保留音频输出、暂停 VideoRenderer，3s 后恢复 | 更"干净"但依赖 Media3 渲染器控制能力，spike 验证 |

设计默认**路径 A**（遮罩），spike 后如 B 可行且成本低再切换。取消倒计时（FR-10.5）= `pause()`+`seekTo(S)`+移除遮罩。

## 4. 状态机细化

### 4.1 播放会话状态（`PlayerPhase`，细化自架构 6.1）

```
IDLE ──load(uri)──▶ LOADING ──READY──▶ READY(暂停)
READY ──play()──▶ COUNTDOWN(3s) ──结束──▶ PLAYING(READY+isPlaying, IMMERSIVE UI)
READY(暂停) ──seek/scrub/step──▶ READY(暂停)          // 交互事务原地
PLAYING ──pause()/双击退出/被打断──▶ READY(暂停)
PLAYING(无选区) ──播完──▶ ENDED(暂停, UI 复位到 0)
PLAYING(选区,单次) ──SelectionMonitor──▶ READY(暂停, 位置=A')
READY/PLAYING ──BUFFERING──▶ READY/PLAYING(子态，UI 缓冲条)
任何态 ──Error──▶ ERROR ──retry/换文件──▶ LOADING
任何态 ──release/切视频──▶ IDLE
```

UI 呈现规则：`LOADING` 全屏 loading；`BUFFERING` 仅进度圈不遮控制；`ENDED` 显示结尾帧 + 播放按钮(从头)。

### 4.2 选区练习状态（`SelectionState`，细化自架构 6.2）

```
IDLE(无选区) ──设A──▶ WAIT_B(A) ──设B(valid)──▶ ACTIVE(A',B')
ACTIVE ──清除──▶ IDLE ；ACTIVE ──重设A──▶ WAIT_B(newA)
ACTIVE ──开连续循环──▶ ACTIVE_LOOP(引擎级循环)
ACTIVE(单次) 播放: IDLE_STANDBY ──play+倒计时──▶ PLAYING_SINGLE ──到B'──▶ IDLE_STANDBY(复位A',退出沉浸)
ACTIVE_LOOP(连续) 播放: ──play+倒计时──▶ PLAYING_LOOP(引擎循环，无 UI 中断)
```

### 4.3 倒计时预听（FR-10）详细时序（路径 A：静止帧遮罩）

> 起点语义（v1.5 需求确认，FR-04.11/I8）：**选区开启 → 起点 S = A'（无论当前帧 C 在哪，先无条件 seek 到 A'）**；选区关闭 → S = 当前帧 C。

```
① 用户点"播放"（CONTROL 态，当前帧=C）
② VM: 起点 S = 选区开启 ? A' : C
   若 S≠C：VM→MGR seekTo(S)（先跳到 A'，选区开启场景；选区关闭 S==C 无跳转）
③ VM: 记录 S；向 manager 发 startCountdown(S)
④ manager: seekTo(max(0, S−3000)) → 截取 S 帧 Bitmap（FrameGrabber，异步）
⑤ 播放器 play()（音视频开始，音频从 S−3s 处起）
⑥ UI: 进入 COUNTDOWN 态：视频 Surface 被 S 帧遮罩覆盖（静止画面）+ 3-2-1 计数动画
⑦ 3s 到（期间音频恰好推进到 S）→ 移除遮罩 → PLAYING(IMMERSIVE)
   验证点 AC-10.2：音频位置与画面 S 偏差 ≤100ms
⑧ 取消（COUNTDOWN 态点取消 / 被打断 ON_STOP）：pause + seekTo(S) + 移除遮罩 → CONTROL
边界：S < 3s → 音频从 0 起播，遮罩维持到引擎位置=S 后 1 帧即移除（倒计时文本仍走满 3s 或按配置缩短）
```

> 复位的衔接：单次区间练习播到 B' 复位到 A'（§5.5）后再次点播放 → 选区仍开启 → S = A' = 当前帧，② 不跳转，直接倒计时，符合"从 A 点（经倒计时预听）开始"（AC-04.4）。

### 4.4 播放流程时序总览（含历史恢复）

```
LibraryScreen 点击条目
 └▶ PlayerViewModel.load(uri)
     ├─(并行) VideoRepository.takePersistablePermission / readMetadata(rotation,duration,fps)
     ├─ PlayerManager.load(uri) → READY
     ├─ PreferenceRepository.loadHistory(uri)
     │    ├─ 存在：seekTo(归一化 positionMs) + setSpeed(speed)
     │    │        + setSelection(A',B') / enableContinuousLoop(flag)
     │    │        + setAudioOffsetMs(offset) + 倒计时配置恢复
     │    └─ 不存在：默认 1.0x、位置 0、无选区
     └─ OrientationAdapter → PlayerScreen 按 rotationDeg 布局（横/竖）
```

### 5.2 帧标记（FR-06）

```
CONTROL 态点"添加标记"
 ├─ FrameGrabber.captureCurrentFrame() → 压缩 ≤320px JPEG → filesDir/marks/<markId>.jpg
 ├─ Dialog：输入自定义文本（可空）→ BookmarkRepository.add(uri, FrameMark(...))
 └─ UI：BookmarkPanel 刷新；TimelineScrubber 画标记点
点击标记：seekTo(mark.timeMs) → 暂停定格该帧（AC-06.2）
编辑/删除：BookmarkPanel 上下文操作
级联：VideoLibraryRepository.deleteVideo → BookmarkRepository.removeAll(uri) + 删缩略图文件（AC-06.4/11.4）
```

### 5.3 视频方向适配（FR-02.9）

```
PlayerScreen 布局策略：
 ├─ rotationDeg ∈ {0, 180} → 默认横屏（resizeMode=FIT，横向全屏）
 ├─ rotationDeg ∈ {90, 270} → 竖屏完整显示（旋转画面/切 portrait Activity）
 └─ rotationDeg 缺失(未知) → 横屏 + 画面手动旋转按钮兜底（R-11）
每次 load 仅计算一次；旋转由系统请求 configuration 变更（不重建播放器，保留 Surface）
验证 AC-02.9：竖拍样例完整无裁切，方向正确。
```

### 5.4 音频延迟校正（FR-08）

```
AudioDelayProcessor : AudioProcessor（media3 管线）
 ├─ delayMs ∈ [−100, +100]，5ms 步进；实现：内部环形缓冲 delaySamples = sampleRate*delayMs/1000
 ├─ 正值(音频延后)：输出滞后 delaySamples
 ├─ 负值(音频提前)：等价视频延后 delaySamples → 由渲染层对视频帧做等量延迟（FrameDelayHelper），或限制负值仅 1.0x 生效（spike 决定，R-13）
 └─ UI：AudioDelayPanel（暂停态）调节 → manager.setAudioOffsetMs → 重建音频链即时生效
持久化：HistoryEntry.audioOffsetMs；恢复时重放
AC-08.1：+80ms 后 3s 内关系稳定
```

### 5.5 播到 B 点复位（单次区间练习，FR-04.3）内部实现

```
PLAYING_SINGLE 期间，SelectionMonitor 以 PositionTick 驱动：
  if (selectionActive && !continuousLoop && enginePosMs >= endMs_aligned && !hasFired) {
      hasFired = true
      player.pause()
      player.seekTo(startMs_aligned, exact=false)   // 落 A' 关键帧
      emit SelectionHit(resetToMs = A')
      // UI: isPlaying=false → 退出沉浸 → CONTROL 态，进度条回 A'
  }
  // hasFired 复位：seek 完成后位置 < B'−50ms 时复位为 false（等待下轮播放）
去抖：触发后 500ms 内忽略 tick（防连续 seek 抖动）
```

> 复位衔接（v1.5，FR-04.11）：复位后停在 A'（CONTROL 态）；此时选区仍开启，用户再点播放 → §4.3 起点 S = A'（无跳变），经倒计时从 A' 起播——与"无论当前帧在哪都从 A 开始"的语义自洽。

### 5.6 连续循环（可选开关，FR-04.9）

```
enableContinuousLoop(true) 且选区存在：
 → 走 LoopMediaSourceBuilder 整链重建原语（§架构 5.4）
 → 位置语义：PositionNormalizer 归一化 enginePos → display（I1）
 → 循环回跳由引擎 AUTO_TRANSITION 完成（UI 不过问），对 PositionTick 过滤跳变
取消开关/清除选区 → 重建回裸源（原语同），seek 回当前归一化位置
```

### 5.7 帧标记沉浸字幕提醒（FR-06.6，v1.5 新增）

**数据流**：
```
BookmarkRepository.list(uri)（进入播放页时加载一次，含空文本标记）
 └─ PlayerViewModel/PlayerUiState.activeCaptions（派生状态）
      └─ MarkCaptionOverlay（Compose，沉浸态渲染）
           └─ 输入：displayPositionMs（250ms PositionTick + 每帧外推值）+ isPlaying + isImmersive
```

**窗口判定算法**（纯函数，放 util 便于单测）：
```
数据：marks = [{id, timeMs, text}]，仅 text.isNotBlank() 参与
窗口：[timeMs − 3000, timeMs + 3000]（单位 ms）
activeCaptions(nowMs) = marks.filter { it.timeMs−3000 <= nowMs <= it.timeMs+3000 }
                         .sortedBy { it.timeMs }
                         .map { it.text }
显示规则：
 ├─ isImmersive && isPlaying && activeCaptions 非空 → 渲染（顶部居中，纵向依次排列，最多 3 条，超出省略号）
 ├─ 否则 → 不渲染（淡出动画 ~150ms）
样式约束（AC-06.6）：
 ├─ 顶部 SafeArea 下沿，垂直居中于屏幕顶部 8%~15% 区域
 ├─ 字号 = 正文小号（12~14sp）；行数 ≤ 2
 ├─ 背景 = 半透明黑色（alpha ~0.45）圆角胶囊；文字白色
 ├─ 点击穿透：Compose 层 pointerInput 不做消费（Modifier.pointerInput{} 空实现 + 无 clickable），
 │   事件落入沉浸丢弃容器（架构 6.3）——不触发任何控制
刷新节流：随 PositionTick（250ms）+ UI 时间外推驱动，无需独立轮询
```

**行为协同**：
```
 ├─ 起播/倒计时结束进入 PLAYING → 字幕监视激活（AC-06.5：T−3s 出现、过 T+3s 消失）
 ├─ pause()/双击退出/播到 B' 复位/ENDED → 字幕立即清空隐藏（AC-06.7）
 ├─ 单次区间练习每轮播放都会再次进入窗口 → 每轮重新提醒（自然行为，不做"仅提醒一次"记忆）
 ├─ seek/拖动（暂停态）不触发字幕（非沉浸）
 └─ 文本留空的标记：仅作为可跳转书签，不产生字幕（FR-06.6）
```

**验证**（映射架构 12 / AC-06.5~06.7）：
```
 ├─ 纯函数单测：activeCaptions 在 3000ms 前后沿正确（T−2999 无、T−3000 有、T+3000 有、T+3001 无）
 ├─ Compose 测试：沉浸态字幕渲染样式/数量上限；暂停后消失
 └─ 仪器：字幕出现期间点击/滑动不暂停、不弹 UI（与 AC-02.6 合并用例）
```

## 8. 错误处理速查

| 场景 | 捕获点 | 用户呈现 |
|------|--------|----------|
| 解码失败/不支持格式 | manager `PlaybackException` | ERROR 态 + 重试/换文件 |
| 文件被移动/删除（IO） | load 失败 | ERROR + 建议重选；清失效条目 |
| seek 卡死 | watchdog（位置 3s 不动 & isPlaying） | ERROR，提示"seek 异常" |
| 循环源重建失败 | LoopMediaSourceBuilder | 回退单次模式 + toast |
| 倒计时被打断（来电/后台） | ON_STOP/AudioFocus | 回 CONTROL 暂停、位置=S |
| 授权失效 | VideoRepository.isUriReadable | 清理条目 + 提示重选 |
| 缩略图生成失败 | FrameGrabber | 占位图，不影响标记 |
| rotation 缺失 | OrientationAdapter | 默认横屏 + 手动旋转按钮 |

错误一律折叠进 `PlaybackUiState.error`，UI 统一渲染（无散落 toast），错误码入日志（可选遥测）。
