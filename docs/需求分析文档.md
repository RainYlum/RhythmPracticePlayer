## 1. 项目概述

### 1.1 背景与动机

音游玩家（如《Project SEKAI》《BanG Dream!》《Arcaea》等）的练习需求与普通视频播放有本质区别：他们需要**反复观看特定难点段落**，从视觉和操作两个维度拆解谱面，研究指法、节奏与判定时机。

市面上的通用播放器具备的视频能力（倍速、A/B 循环、逐帧等）与本产品的差距，见 §2.3 竞品对照。与通用工具相比，本产品的差异化不在单一能力，而在**"变速不变调 + 精确 A/B 循环 + 帧级定位 + 练习状态记忆"的组合与音游特化交互**：

- 针对音乐节奏的**变速不变调**（而非改变音高的普通变速）；
- 针对难点段落的**高精度 A/B 循环**（显示真实循环边界、支持 A/B 微调）；
- 针对谱面拆解的**帧级/毫秒级定位**；
- 针对练习流程的**状态记忆**（位置、选区、倍速一次恢复）；
- 为谱面确认者提供的**音频延迟校正（±100ms）**与**毫秒级时间显示**。

本产品定位为**音游练习专用工具类 App**：以"精确控制播放节奏"为核心能力，将"看手元、拆谱面"这一练习流程做到极致。

### 1.2 项目目标

| 编号 | 目标 | 衡量标准 |
|------|------|----------|
| G1 | 提供流畅稳定的本地视频播放能力 | 1080p 视频在主流中端机型上可流畅播放 |
| G2 | 提供 **0.5x~1.0x 六档固定倍速**且**不变调**（默认 1.0x） | 变速操作响应 ≤ 100ms；变速后音画同步；全部档位基频偏移 ≤ 2%（见 AC-03.2） |
| G3 | 提供 A/B 点区间练习：**播到 B 点自动暂停并复位到 A 点**，支持连续循环开关 | 播放到 B 点后 500ms 内暂停并跳回 A 点（±1 个关键帧间隔）；UI 显示真实对齐边界 |
| G4 | 暂停状态下可实时调整（倍速/进度/A 点/B 点），调整时视频实时展示 | 调整进度类操作画面反馈 ≤ 300ms；步进最小 0.1s |
| G5 | 提供练习场景的状态记忆 | 再次打开同一视频可恢复上次位置与选区（位置为归一化后的真实时间轴值） |
| G6 | 提供**沉浸式练习模式**与**3 秒倒计时预听** | 播放中仅保留退出按钮，点击/滑动不影响播放；倒计时结束瞬间音画对齐起播 |
| G7 | 提供**视频库管理**：导入视频后可备注、可从主页管理（含删除） | 首次导入弹备注窗（可留空）；主页可查看/编辑备注；删除视频后其帧标记等关联数据一并清除 |
| G8 | 提供**帧标记**：在任意帧添加自定义文本标记，跨会话保留 | 标记随视频保留（重进仍在）；删除视频后清除 |
| G9 | 显示**随视频方向自动适配横竖屏**，默认横屏 | 竖拍/横拍视频均完整显示，无需手动旋转 |
| G10 | 提供**音频延迟校正 ±100ms** | 应对录制音画不同步；调整即时生效并随历史持久化 |

### 1.3 项目范围

- **范围内**：本地视频文件导入与视频库管理（备注、删除）、播放、变速、A/B 区间练习、精细定位、帧标记、历史记录、横竖屏方向适配、音画同步校正。
- **范围外（本书不涉及，列入后续版本）**：在线视频/谱面下载、谱面解析与自动识别、多视频对比播放、投屏、后台音频播放、多平台（iOS/桌面）。

### 1.4 术语定义

| 术语 | 说明 |
|------|------|
| 手元 | 玩家录制的手指操作视频，是练习参考的主要素材 |
| 谱面确认 | 谱面谱师发布前对谱面进行可视化确认的过程 |
| A/B 点 | 循环区间的起点与终点时间标记 |
| 不变调（pitch-preserving） | 变速播放时音频音调保持原样，避免"花栗鼠"效果 |
| 关键帧（I 帧） | 视频可解码的独立帧，Seek 精度受其间隔影响 |
| 选区循环 / 区间练习（Loop） | 设置 A/B 区间后，播放到 B 点自动暂停复位到 A 点（默认单次），或开启连续循环无缝反复（可选开关） |
| 视频库（主页） | 已导入视频的管理列表，支持查看、备注、删除 |
| 视频备注 | 用户为视频添加的自定义说明文字，用于管理识别 |
| 帧标记 | 在视频某一帧添加的带自定义文本的可跳转标记（缩略图 + 时间戳 + 文本） |
| 视频方向 | 视频录制时的旋转方向（元数据 rotation 0/90/180/270），决定播放时横竖屏适配 |
| 音频延迟 | 相对视频的音频时间偏移（±100ms），用于校正录制造成的音画不同步 |

## 2. 目标用户与使用场景

### 2.1 用户画像

| 画像 | 描述 | 核心诉求 |
|------|------|----------|
| **P1 音游练习玩家** | 活跃在音游圈，日常通过观看手元学习/优化指法；练习量大，常反复观看同一段落 | 快速定位难点、慢速/逐帧拆解、循环练习 |
| **P2 谱面制作者/谱面确认者** | 制作谱面后进行确认，需精确核对谱面与音频的对应关系 | 高精度定位、变速核对节奏、帧标记记录问题点 |
| **P3 轻度用户** | 偶尔观看手元/录屏，需求接近普通播放器 | 基础播放与倍速即可 |

### 2.2 核心使用场景（用例）

| 用例编号 | 用例名称 | 触发者 | 优先级 |
|----------|----------|--------|--------|
| UC-01 | 导入本地视频（含首次备注） | P1/P2/P3 | P0 |
| UC-02 | 基础播放控制（播放/暂停/拖动进度） | 全部 | P0 |
| UC-03 | 倍速播放（六档预设） | P1/P2 | P0 |
| UC-04 | 设置 A/B 点并区间练习（播到 B 复位 / 连续循环） | P1/P2 | P0 |
| UC-05 | 帧级/微步定位 | P1/P2 | P1 |
| UC-06 | 添加/跳转帧标记；播放中字幕提醒 | P2 | P2 |
| UC-07 | 恢复播放历史 | P1/P2 | P2 |
| UC-08 | 视频库管理（主页：列表/备注/删除） | P1/P2/P3 | P1 |
| UC-09 | 方向适配播放（横/竖屏随视频） | 全部 | P0 |
| UC-10 | 音频延迟校正 | P1/P2 | P2 |

**典型用户旅程（UC-01 ~ UC-05 组合，P1 用户）：**

> 玩家打开 App → 主页（视频库）点"导入"，从本地选择某曲目的手元视频 → 首次导入弹出备注窗口（填写"某曲目—难点段练习"或留空）→ 进入播放页：视频自动按录制方向横/竖屏完整显示 → 在暂停界面将速度调到 0.6x（慢速拆解），拖到难点段起点附近，用点按步进/拖动精确定位 → 分别设置 A 点、B 点，开启练习模式 → 点击播放：画面先出现 **3 秒倒计时**，音频从 A 点前 3 秒悄悄进入（帮助跟节奏），倒计时结束音画对齐开始播放 → 播放中进入**沉浸模式**（仅左上角退出按钮，点击/滑动不打断视频）→ 播放到 B 点自动暂停、进度条复位到 A 点 → 在某关键帧添加**帧标记**（如"这里换指法"）→ 用 0.5x~0.9x 反复听难点段节奏、微调 A/B 点；若发现音画不同步，打开**音频延迟 ±100ms** 校正 → 再次播放 → 结束练习后退出，下次打开自动恢复到上次位置与选区，帧标记仍在 → 回到主页可按备注快速找到该视频。

### 2.3 竞品对照与差异化（P2-1 修订补充）

> 对抗性审查指出：A/B 循环、逐帧、0.25x 变速等**单项能力**在通用播放器中已存在，不能作为"通用播放器不具备"来论证差异化。下表为事实性竞品对照，差异化重新定位为**组合能力 + 音游特化交互**：

| 能力 | VLC（桌面/移动） | MX Player | YouTube | 系统相册 | 本产品 |
|------|------------------|-----------|---------|----------|--------|
| 倍速变速 | 0.25x 起 | 有 | 0.25x~2x | 无 | **0.5x~1.0x 六档固定（默认 1.0x），无滑块** |
| 变速不变调 | 桌面保音调 | 选项 | 默认保音调 | — | **默认保音调（Sonic 实测验收）** |
| A/B 循环 | 桌面有，移动弱 | 有（A/B） | 无（仅整段循环） | 无 | **A/B + 微调 + 真实边界显示 + 播到 B 复位** |
| 帧级步进 | 桌面有 | 无/弱 | 无 | 无 | **暂停态实时步进（最小 0.1s，帧级可选）** |
| 沉浸式练习 | 无 | 无 | 无 | 无 | **播放中全程无 UI 干扰 + 3s 倒计时预听** |
| 练习状态记忆 | 进度记忆 | 进度记忆 | 进度记忆 | 无 | **位置+选区+倍速+倒计时开关一体恢复** |
| 音游特化 | 无 | 无 | 无 | 无 | **A/B 微调、毫秒显示、音频延迟校正、波形参考线、倒计时预听** |

**结论**：产品差异化 = "变速不变调（六档 0.5x~1.0x）+ 精确 A/B 区间练习（播到 B 复位 + 连续循环开关）+ 沉浸式播放与倒计时预听 + 帧级定位 + 状态记忆 + 音游特化工具"的**组合与交互**，而非单一能力。该定位建议经 5~10 人目标用户访谈验证（对应 §5.2 假设 A-05）。

### 3.2 FR-01 视频源选择（P0）

**用户故事**：作为音游玩家，我想要从手机本地选择一个视频文件并导入视频库，以便观看手元或谱面确认视频、后续从主页管理。

**功能点**：

| 编号 | 功能点 | 要求 |
|------|--------|------|
| FR-01.1 | 文件选择 | 通过系统文件选择器（`ACTION_OPEN_DOCUMENT`）选择本地视频，支持 mp4、mov、mkv、webm、3gp 等主流容器 |
| FR-01.2 | 格式校验 | 选择后校验可解码性；不可解码时给出明确错误提示且不崩溃 |
| FR-01.3 | 权限 | 无需申请存储权限（依赖系统文件选择器）；后续若支持"最近视频"列表再评估 `READ_MEDIA_VIDEO` |
| FR-01.4 | 加载反馈 | 大文件加载期间展示进度/loading，避免界面无响应（ANR） |
| FR-01.5 | 导入入库 | 选择成功后登记到**视频库**（主页可见）；同一文件重复导入不产生重复条目 |
| FR-01.6 | 首次备注 | **首次导入视频时弹出备注窗口**（可留空，默认=文件名）；后续在主页可编辑（见 FR-11） |

**验收标准（AC）**：

- AC-01.1 系统文件选择器可正常打开且只展示可播放的视频类文件。
- AC-01.2 选择一个合法 mp4（1080p）后 3s 内出现首帧画面。
- AC-01.3 选择一个损坏或不可播放的文件时，出现"无法播放该视频"提示，App 不崩溃且不入库。
- AC-01.4 选择大文件（≥500MB）时不发生 ANR。
- AC-01.5 导入成功后视频出现在主页视频库；重复导入同一文件不产生重复条目。
- AC-01.6 首次导入弹出备注窗口，可输入自定义文本或留空（留空默认文件名）；确认后进入播放。

### 3.3 FR-02 播放控制（P0）

**用户故事**：作为音游玩家，我想要播放/暂停并自由控制进度，练习时不被 UI 打扰，以便专注观看手元、快速定位想要研究的段落。

**功能点**：

| 编号 | 功能点 | 要求 |
|------|--------|------|
| FR-02.1 | 播放/暂停 | 暂停界面（控制面板可见）点击播放按钮开始播放；**沉浸模式下点击画面/滑动屏幕不暂停、不唤出任何 UI**（见 FR-02.6） |
| FR-02.2 | 进度拖拽 | **暂停状态下**拖动进度条：拖动过程中**视频实时展示对应帧画面**（seek 预览，反馈 ≤ 300ms），松手后定位到目标位置 |
| FR-02.3 | 快进/快退 | 提供 ±10s 快捷键，长按连续触发 |
| FR-02.4 | 状态展示 | 展示当前时间/总时长、缓冲进度、倍速标识；提供**毫秒级时间显示开关**（谱面确认用，精确到 1ms） |
| FR-02.5 | 播放结束 | **播放到结尾自动停止（暂停态），进度条复位到开头，并显示控制 UI**（不自动开始）；若设置了 B 点则复位到 A 点（见 FR-04.3） |
| FR-02.6 | 沉浸式播放 | **播放中 UI 仅保留左上角退出按钮**；用户自由点击/滑动屏幕不影响视频播放；进入沉浸模式时机=点击播放后 |
| FR-02.7 | 双击退出 | **双击左上角退出按钮**→ 暂停视频、退出沉浸模式、显示完整控制 UI（单击退出按钮不响应，防止误触） |
| FR-02.8 | 退出确认 | 退出播放页（离开视频）时按 FR-07.1 保存历史并返回上一页 |
| FR-02.9 | 方向适配 | **支持横屏与竖屏两种显示，随视频方向自动适配，默认横屏**：读取视频旋转元数据（rotation 0/90/180/270），竖拍（90°）视频自动以竖屏/旋转画面完整显示，横拍视频默认横屏；画面使用等比缩放完整显示（不裁切、不拉伸） |

**验收标准（AC）**：

- AC-02.1 暂停界面点击播放后开始播放，播放中点击画面/滑动屏幕**不暂停、不改变任何 UI 状态**。
- AC-02.2 暂停态拖动进度条时，画面按拖拽位置实时更新（≤300ms），松手后定位正确。
- AC-02.3 播放过程中（持续播放且无缓冲时）UI 时间文本与画面同步误差 ≤ 100ms（实现路径：UI 端逐帧外推 `lastTick + speed×(now−lastTickTime)`，详见架构 6.3；此项依赖外推算法单测覆盖）。
- AC-02.4 播放到结尾停止，进度条复位到开头，控制 UI 显示；再次点击播放从开头继续。
- AC-02.5 毫秒显示开关开启时，时间文本刷新到 1ms 精度且不卡顿（≥30fps UI 帧率）。
- AC-02.6 播放中仅左上角退出按钮可见，其余 UI 全部隐藏；点击/滑动屏幕无响应（不暂停、不弹控制台）。
- AC-02.7 双击左上角退出按钮：暂停、退出沉浸、显示完整 UI；单击不响应。
- AC-02.8 退出播放页后重进，历史位置/选区/倍速已恢复（依赖 FR-07）。
- AC-02.9 打开竖拍（rotation=90°）视频时画面完整显示且方向正确（无需手动旋转）；横拍视频默认横屏完整显示；两种方向均不裁切/拉伸。

### 3.4 FR-03 倍速播放（P0）

**用户故事**：作为音游玩家，我想要放慢视频但**声音不变调**，以便在不失真地听清节奏的前提下拆解指法。练习场景需要慢速档位（最低 0.5x）与常速 1.0x（默认），档位化设计保证每次切换都是可预期、可复现的（无需连续微调）。

**功能点**：

| 编号 | 功能点 | 要求 |
|------|--------|------|
| FR-03.1 | 预设档位 | **固定六档：0.5x / 0.6x / 0.7x / 0.8x / 0.9x / 1.0x（默认 1.0x）**，一键切换；不提供其他档位 |
| FR-03.2 | ~~滑动微调~~ | **不支持用户滑块调整**（v1.4 废弃：倍速仅限六档预设，避免误触与不可复现的中间倍速） |
| FR-03.3 | 不变调 | 变速时必须保持音调不变（TimeStretching 音频处理），禁止出现"花栗鼠"音效（音调漂移） |
| FR-03.4 | 变速即时生效 | **暂停状态下**变速即时生效，无需重启播放，且音画保持同步；播放中不可变速（沉浸模式无控制面板） |
| FR-03.5 | 状态记忆 | 当前档位在播放期间与视频绑定显示，退出后可恢复（**最小恢复：位置/倍速档位/选区随播放会话落盘，随 FR-07 v1.0 一并交付**） |

**验收标准（AC）**：

- AC-03.1 **六个档位（0.5/0.6/0.7/0.8/0.9/1.0）**均可一键切换，切换在 100ms 内生效；**不存在滑块/连续倍速输入**。
- AC-03.2 全部档位（0.5x~1.0x）播放时音调保持客观达标：固定测试音/曲目段过变速管线后，FFT 基频偏移 ≤ 2%（自动化断言）；"花栗鼠"效应（音调漂移）必须为 0；0.5x 档辅以人工盲测（固定强节拍曲目 + ≥3 名验收人对"节拍感可辨性"一致通过）——0.5x 已是本产品最低速，音质须作为发布准入项（不达标则集成 SoundTouch 替换，见架构 ADR-01）。
- AC-03.3 变速后 3s 内音画重新同步，无持续声画错位。
- AC-03.4 ~~滑块一致性~~（随滑块废弃删除）。
- AC-03.5 退出播放页后重进，恢复上次档位（默认 1.0x）。

### 3.5 FR-04 选区循环 / 区间练习（P0）⭐ 核心差异化功能

**用户故事**：作为音游玩家，我想要为难点段落设置 A/B 两个时间点，练习时**播放到 B 点自动暂停并复位到 A 点**，进入沉浸式观看，一遍练完回到起点准备下一遍；也可以选择开启连续循环无缝反复播放。

**功能点**：

| 编号 | 功能点 | 要求 |
|------|--------|------|
| FR-04.1 | 设置 A 点 | 暂停状态下，将当前时间标记为 A 点；A 点必须在 B 点之前（或为未设置状态） |
| FR-04.2 | 设置 B 点 | 暂停状态下，将当前时间标记为 B 点；B 点必须晚于 A 点，否则提示用户 |
| FR-04.3 | 播到 B 点复位 | **播放到达 B' 点时暂停视频、退出沉浸模式、显示控制 UI，进度条自动跳回 A' 点**（就绪状态，等待下一次播放）；A'/B' 为对齐关键帧后的真实边界 |
| FR-04.4 | 取消选区 | 一键清除 A/B 选区，恢复整段播放 |
| FR-04.5 | 区间可视化 | 暂停界面进度条上以高亮色带展示 A/B 区间（按对齐后真实边界绘制）；点击色带可直接跳转到 A 点 |
| FR-04.6 | 边界处理 | A 点不能等于 B 点；区间最短 **≥2 帧时长且 ≥100ms**（取较大者）；不足时提示"区间过短"；<0.5s 区间提示"起止按关键帧对齐、内容可能近似" |
| FR-04.7 | 与变速/暂停协同 | 区间练习在任意倍速下逻辑保持正确（暂停时停在当前位置，不强制跳转） |
| FR-04.8 | A/B 微调 | 对已设置的 A/B 点支持 ±1 帧 / ±10ms / ±100ms 步进微调，微调后实时刷新循环区间与色带（nudge 功能） |
| FR-04.9 | 连续循环开关 | **可选开关（默认关）**：开启后播放到 B 点不暂停，自动跳回 A 点继续播放（无缝循环）；关闭时按 FR-04.3 行为（播到 B 点暂停复位） |
| FR-04.10 | 倒计时联动 | 点击播放（无论单次/连续循环）统一进入 FR-10 的 3 秒倒计时预听流程 |
| FR-04.11 | 播放起点语义（v1.5 需求确认） | **已设置 AB 选区时：无论当前帧在什么位置（A 前 / 区间内 / B 后 / 任意位置），点击播放都会先自动跳转到 A' 点，再从 A' 经倒计时预听起播**；关闭 AB 选区后：点击播放**从当前帧所在位置**开始（不跳转、不从开头） |

**验收标准（AC）**：

- AC-04.1 设置 A、B 点后，播放到达 B 点即自动暂停、退出沉浸、显示 UI，进度条复位到 A 点（偏差 ≤ 关键帧间隔），循环 3 次均正确。
- AC-04.2 （连续循环开关开启时）播放越过 B 点跳回 A 点继续播放，连续循环 10 次无异常；循环中 UI 显示位置保持在 A'~B' 区间内（归一化位置，见架构 6.3）。单次模式（开关关闭）不进入此路径。
- AC-04.3 B 点早于 A 点时给出明确提示且不创建选区。
- AC-04.4 播到 B 点复位后，再次点击播放从 **A 点**（经倒计时预听）开始。
- AC-04.5 区间最短限制生效：A=B 或区间 < 最小长度（≥2 帧且 ≥100ms）时提示不可设置。
- AC-04.6 选区激活后 UI 展示的对齐值 A'/B' 与引擎实际边界一致（偏差 ≤ 关键帧间隔）。
- AC-04.7 A/B 微调操作后，区间与色带在 500ms 内完成更新，播放不中断。
- AC-04.8 （连续循环开关=关）无选区时播放到结尾按 FR-02.5 复位到开头。
- AC-04.9 播放起点语义：① 选区开启时，把当前帧分别置于 A 前、区间内、B 后、视频末尾四种位置再点播放，均先跳转到 A' 再从 A' 起播（含倒计时）；② 关闭选区后，把当前帧置于非 0 位置点播放，从当前帧起播不跳转；③ 选区开启但当前位置恰在 A' 附近（±1 帧）时，不产生可见跳变。

### 3.6 FR-05 精细定位（P0）

**用户故事**：作为谱面确认者，我想要在**暂停状态下**精确移动播放位置：大幅调整用拖动进度条（实时看画面），小幅调整用点按前后按钮（最小 0.1s），以便核对每个 note 与节拍的对应关系。

**功能点**：

| 编号 | 功能点 | 要求 |
|------|--------|------|
| FR-05.1 | 拖动定位 | 暂停态拖动进度条，**视频画面实时跟随展示**（seek 预览，反馈 ≤300ms）；松手后定格在目标位置 |
| FR-05.2 | 点按步进 | 暂停态提供前/后调整按钮，**单次步进 0.1s**（可切换 1s 档），点按即时生效；反复点按连续步进 |
| FR-05.3 | 帧率适配 | 需要帧级精度时按视频实际帧率计算步进间隔；帧率不可得时（部分容器/VFR）降级 30fps 近似并在 UI 提示"步进粒度不精确" |
| FR-05.4 | 步进状态语义 | **暂停态步进 = 定位并保持暂停**（播放中无控制面板，不提供步进；见 FR-02.6 沉浸模式） |
| FR-05.5 | 帧级步进（可选增强） | 渐进式 mp4 等支持精确 seek 的格式提供**逐帧步进**（双轨方案：帧精确/关键帧步进），P1 期交付 |

**验收标准（AC）**：

- AC-05.1 暂停态拖动进度条，画面按拖拽位置实时更新（≤300ms）；松手后定格在目标位置并保持暂停。
- AC-05.2 暂停态点按"前进 0.1s"10 次，位置回读恰为 1.0s（误差 ≤ 关键帧间隔 + 50ms，回读以播放器实际位置为准）。
- AC-05.3 1s 档点按 5 次后位置回读恰为 5.0s（误差 ≤ 关键帧间隔 + 100ms）。
- AC-05.4 步进与拖动操作均保持暂停态，不触发自动播放。
- AC-05.5 （帧级步进，P1）渐进式 mp4 连续步进 10 次画面每次更新为独立时间戳帧，累计位移 ≈ 10 帧时长（±2 帧）；不支持精确 seek 的格式显示"近似步进"提示。exact-seek spike（MVP 第 1 周）结论决定轨道 A 支持矩阵。

### 3.7 FR-06 帧标记 / 书签（P2，v1.3 升级）

**用户故事**：作为练习玩家或谱面确认者，我想要在视频的某一帧做标记并写下自定义文本（如"换指法处""疑似漏判"），之后能快速跳回查看；退出再进同一视频标记仍保留。练习播放（沉浸模式）到标记附近时，希望屏幕上以小字提醒我"这里要看/要练什么"，避免错过关键点。

**功能点**：

| 编号 | 功能点 | 要求 |
|------|--------|------|
| FR-06.1 | 添加帧标记 | **在暂停态当前帧添加标记**：自动捕获该帧缩略图 + 记录时间戳（归一时间轴真实值）+ **自定义文本输入**（可留空） |
| FR-06.2 | 标记列表 | 以列表/时间线形式展示（缩略图 + 时间 + 文本）；点击跳转播放并定格该帧 |
| FR-06.3 | 编辑/删除 | 可编辑标记文本；单条删除与清空全部 |
| FR-06.4 | 持久化 | 帧标记与该视频关联保存（键见架构 8.1），重开 App 后仍可恢复；授权失效时清理并提示 |
| FR-06.5 | 删除视频联动 | **从视频库删除视频后，该视频的所有帧标记一并清除（不保留）**（见 FR-11.4） |
| FR-06.6 | 沉浸播放字幕提醒 | **沉浸模式播放中，当播放位置进入某帧标记时间点 ±3s 窗口时，在屏幕顶部以小字显示该标记的文本**：半透明背景、字号小、不抢焦点、不响应点击、不打断播放；离开窗口（或暂停/退出沉浸）即消失。有文本的标记才提醒；多个标记窗口重叠时顶部依次排列显示 |

**验收标准（AC）**：

- AC-06.1 暂停态添加帧标记后，缩略图/时间/文本立即出现在标记列表上。
- AC-06.2 点击标记跳转，画面 500ms 内定位到标记时间点并显示该帧（标记存归一化时间值，循环态下跳转无累计偏差）。
- AC-06.3 重启 App 后标记仍在（针对同一视频文件，且 Uri 授权可达）。
- AC-06.4 删除该视频后，其全部帧标记被清除且不残留。
- AC-06.5 字幕提醒：标记位于 T 时刻，沉浸播放中位置到达 T−3s 时顶部出现该标记文本小字；播放越过 T+3s 后自动消失；文本留空的标记不提醒。
- AC-06.6 字幕提醒不干扰练习：提醒出现/消失过程中播放不中断、不弹控制面板；字幕区域点击/滑动仍被忽略（不透传成控制操作）；字号小于正文、背景半透明不遮挡视频主体。
- AC-06.7 字幕提醒与播放状态协同：暂停、退出沉浸、播到 B 复位后字幕立即消失；重新播放再次进入窗口时重新提醒。

### 3.9 FR-08 音频延迟校正（P2）

**验收标准（AC）**：

- AC-09.1 波形在进入播放页后 3s 内渲染完成（1080p mp4）。
- AC-09.2 节拍参考线开启/关闭即时生效，与进度缩放联动对齐。

### 3.11 FR-10 倒计时预听（P0）⭐ 练习启动仪式

**用户故事**：作为音游玩家，我点击播放后希望有 3 秒"预备拍"——画面先定格在起点，音频从起点前 3 秒开始播放让我跟住节奏，倒计时结束画面与音频精确对齐开始播放，这样练习一遍时节奏是稳的。

> **机制说明**：点击播放 → **先确定起点 S**（按 FR-04.11：有选区时 S = A'（无论当前帧在哪都先跳转），无选区时 S = 当前暂停位置）→ 视频画面**静止**在 S → **音频从 S−3s 的位置开始播放** → 3 秒倒计时（UI 显示 3-2-1）→ 倒计时结束**视频开始播放**，此刻音频恰好推进到 S，**音画对齐**。

**功能点**：

| 编号 | 功能点 | 要求 |
|------|--------|------|
| FR-10.1 | 倒计时时长 | 固定 **3 秒**（可配置 0/3/5s，随历史持久化；默认 3s，0s=关闭预听直接播放） |
| FR-10.2 | 画面静止 | 倒计时期间视频画面保持显示起点帧（不播放、不闪动、不黑屏） |
| FR-10.3 | 音频先行 | 倒计时期间**音频从 (起点 − 3s) 位置开始播放**（起点前不足 3s 则从 0 起播）；遵循当前倍速 |
| FR-10.4 | 对齐起播 | 倒计时结束瞬间：视频开始播放、音频继续推进，**音画严格对齐于起点**（无声画错位） |
| FR-10.5 | 取消 | 倒计时期间支持取消（返回暂停态）；取消后位置回退到起点（静止） |
| FR-10.6 | 与选区联动 | 有选区时起点 S = **A'**（无条件先跳转，FR-04.11），倒计时结束播放 A'→B'（单次/连续循环按 FR-04.9 开关）；无选区时 S = 当前暂停位置 |

**验收标准（AC）**：

- AC-10.1 点击播放后进入 3 秒倒计时：画面静止、音频从起点前 3s 起播、UI 显示 3-2-1。
- AC-10.2 倒计时结束瞬间视频开始播放，音频位置与画面位置偏差 ≤ 100ms（声画对齐，NFR-02.1 口径）。
- AC-10.3 起点前不足 3s 时音频从 0 起播，倒计时仍满 3s（或按可播放时长缩短，以配置为准），不报错。
- AC-10.4 倒计时期间六档倍速（0.5x~1.0x）任意档下音频先行播放正常（符合倍速）。
- AC-10.5 倒计时期间取消：返回暂停态，位置停在起点，无残留音频。

### 3.12 FR-11 视频库管理 / 主页（P1）

**用户故事**：作为玩家，我导入了多个手元视频后，希望有一个主页视频列表管理它们——给视频加备注方便识别、编辑备注、删除不再需要的视频（连同它的帧标记一起清掉）。

**功能点**：

| 编号 | 功能点 | 要求 |
|------|--------|------|
| FR-11.1 | 主页列表 | **主页展示视频库**：每个条目显示缩略图、备注/名称、最近播放进度、帧标记数；按最近导入/最近播放排序 |
| FR-11.2 | 查看/编辑备注 | 主页可查看并编辑视频备注（原名/自定义文本）；编辑即时保存 |
| FR-11.3 | 进入播放 | 点击条目进入播放页（恢复该视频历史：位置/选区/倍速/音频延迟/倒计时配置） |
| FR-11.4 | 删除视频 | 从库中删除条目：**删除该视频的备注、帧标记、播放历史等全部关联本地数据**；提示确认；不删除用户手机上的源文件（SAF 只读，见范围说明） |
| FR-11.5 | 去重 | 同一源文件（按文档 ID 识别）只保留一个库条目 |

**验收标准（AC）**：

- AC-11.1 导入成功的视频出现在主页列表；主页可按最近导入排序。
- AC-11.2 主页编辑备注后立即生效；删除备注后显示文件名。
- AC-11.3 从主页点击视频进入播放页，恢复上次位置/选区/倍速/音频延迟（依赖 FR-07）。
- AC-11.4 删除视频时弹确认；确认后该视频从列表消失，其帧标记、历史、备注全部清除；源文件仍保留。
- AC-11.5 重复导入同一文件不产生重复条目（以文档 ID 归一）。

## 5. 约束与假设

### 5.1 约束

| 编号 | 约束 |
|------|------|
| C-01 | 首版仅支持 Android 平台（技术基线：Media3 ExoPlayer） |
| C-02 | 播放引擎能力边界：单视频线性播放，不做多轨/拼接/滤镜 |
| C-03 | 首版不做在线内容与账号体系，纯本地单机 |
| C-04 | 关键帧间隔导致的 Seek 精度物理上限（H.264 常见 GOP 250ms~1s）不可完全消除；**帧精确步进仅渐进式 mp4 等精确 seek 格式可用（轨道 A），其余格式降级关键帧步进（轨道 B）并在 UI 明示**，见 FR-05 双轨方案 |
| C-05 | 倍速仅 **0.5x~1.0x 六档固定（默认 1.0x）**，为产品决策（练习慢放 0.5x 起、无快进需求；档位化保证可复现）；最低 0.5x 的瞬态保真作为发布准入项，验收与 SoundTouch 预案见 AC-03.2/ADR-01 |
| C-06 | MVP 第 1 周必须完成 exact-seek spike 与 0.5x 档音质验证，其结果决定 FR-05 轨道范围与 AC-03.2 的发布口径（见 §7 R-02/R-03b） |

### 5.2 假设

| 编号 | 假设 |
|------|------|
| A-01 | 目标用户视频素材以 mp4/H.264 为主，HEVC 占比较低（**待验证**：建议 5~10 人用户访谈确认素材构成） |
| A-02 | 用户设备以中端安卓机为主（骁龙 6/7 系或同级），支持硬解 H.264 |
| A-03 | 用户训练素材以**竖屏录制手元**（rotation≈90°）为主，播放时默认横屏、竖拍视频随方向适配完整显示（FR-02.9 依据此假设设计，待访谈验证占比） |
| A-04 | 首版无需云同步；用户可接受本地历史 |
| A-05 | 差异化组合（变速不变调 + 精确 A/B 循环 + 帧级定位 + 状态记忆）足以让目标用户从通用播放器迁移（**待验证**：见 §2.3 竞品对照，需访谈/问卷验证迁移动机） |

## 7. 需求风险与应对

> 修订说明（P1-7/P2-6）：修正 R-02 的 API 名称（原"MinimalSeek"并非 ExoPlayer 存在的策略），并补充对抗性审查识别的核心风险。

| 编号 | 风险 | 影响 | 等级 | 应对 |
|------|------|------|------|------|
| R-01 | 部分编码（厂商 HEVC / 特殊 mkv）无法硬解或解码失败 | 用户体验（播放失败） | 高 | 异常降级软解（`setEnableDecoderFallback(true)`）；失败提示+换文件引导；兼容矩阵测试 |
| R-02 | 帧级步进（FR-05.5 轨道 A）可行性未验证即投入开发 | 核心体验（P1 功能） | 高 | **MVP 第 1 周 exact-seek spike**（mp4/mkv 样例集真机验证），结论决定轨道 A 范围；备选 `SeekParameters.EXACT` / `getFrameAtTime(OPTION_CLOSEST)`，见 FR-05 双轨方案 |
| R-03 | 变速 + 区间练习组合下音画不同步 | 核心体验 | 中 | ExoPlayer `seekWhilePlaying` 与时钟校准测试用例覆盖；{区间练习 × 变速 0.1/1.5 × 暂停/seek} 组合验收矩阵 |
| R-03b | Sonic 在 **0.5x（最低档）** 下强节拍素材瞬态质量（"节拍感"是否可辨）| 核心体验（最低档） | 中 | 第 1 周音质盲测（固定强节拍曲目 ≥3 人，0.5x 档）；不达标则 0.5x 档集成 SoundTouch（自定义 AudioProcessor）替换 Sonic，见 ADR-01 修订入口。倍速下限从 0.1x 收敛到 0.5x 后，已脱离 Sonic 高危区（v1.4 修订，风险等级由中高降为中） |
| R-03c | 倒计时预听（FR-10）音画对齐实现：音频先行 3s 与视频静止的引擎级协调复杂 | 核心体验（P0 功能） | 中高 | 第 1 周 spike 验证"音频先行 3s + 画面定格"的实现路径（音频轨先行/叠加静音视频轨），确定架构方案后再定稿 FR-10 AC |
| R-04 | 低端机型 1080p 软解发热/卡顿 | 性能 | 中 | 硬解优先；检测设备能力降级；省电模式 |
| R-05 | 后台/来电打断导致播放状态错乱 | 稳定性 | 低 | 生命周期统一处理（onPause 暂停、onResume 恢复）；AudioFocus 策略二选一写死（见架构 10 章） |
| R-06 | Google Play 政策变化（如存储、权限、崩溃遥测披露） | 合规 | 低 | SAF 方案天然规避存储权限；崩溃遥测 opt-in + 隐私政策披露；持续跟踪政策 |
| R-07 | `takePersistableUriPermission` 在部分厂商/第三方 provider 失效或用户清数据，导致 FR-06/07 恢复静默失效 | 体验（P2/P1 功能） | 中 | 启动时校验 Uri 可达性，不可读则清理条目并提示重选；键用 Uri 字符串/文档 ID 而非单向 hash（见架构 8.1/8.2） |
| R-08 | mkv + VBR 音频 seek 精度差/时间映射异常 | 兼容性 | 中 | 兼容矩阵专项；seek 后位置回读校准；异常时提示限制 |
| R-09 | 主观类验收（听感/黑屏）无法机器回归，版本准入争议 | 流程 | 中 | AC 改为客观判据（FFT 基频偏移、黑帧计数）+ 固定人工盲测协议，见 AC-03.2/AC-04.2 |
| R-10 | 沉浸模式误触：单击/滑动被用户当作"应该有反馈"但无响应，或双击退出被误触发 | 易用性 | 低 | 首次使用引导说明；单击退出按钮轻反馈（震动/提示"双击退出"）；双击判定窗口 300ms 防误触 |
| R-11 | 视频方向识别失败（无 rotation 元数据/HEVC 方向信息缺失）导致画面旋转错误 | 体验 | 中 | 读取 `METADATA_KEY_VIDEO_ROTATION`；缺失时默认横屏并允许用户手动旋转（FR-02.9 兜底） |
| R-12 | 帧标记缩略图存储膨胀（大量标记占用存储） | 存储 | 低 | 缩略图压缩（≤ 320px 宽 JPEG）；删除视频联动清理缩略图文件；上限提示 |
| R-13 | 音频延迟校正（FR-08）实现依赖音频管线扩展，与 Sonic 变速管线叠加时的稳定性 | 核心体验 | 中 | MVP 第 1 周 spike 验证「延迟 AudioProcessor + Sonic」共存；不达标则延迟校正仅支持 1.0x 或改期 |
